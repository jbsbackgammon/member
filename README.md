# 会員情報 (`member`)

JBS向けの会員情報管理・名札出力ツールです。

## 機能

- 名前 / 名前英語をリスト管理
- 顔写真を1人につき複数登録
- 顔写真のうち1枚をメイン画像に指定
- 名札用の任意文言と帯色を会員ごとに設定
- チェックした会員だけを名札用紙として出力
- A4縦 1ページ8枚（2列 × 4段）
- 8名を超えた場合は自動で複数ページ化
- JSONバックアップ / 復元（顔写真を含む）
- `noindex` / `robots.txt` により検索エンジンのクロールを抑止

## データ保存

会員情報と顔写真は IndexedDB を使ってブラウザ内に保存します。GitHubリポジトリや外部サーバーには送信しません。

そのため、別PC・別ブラウザで同じ情報を利用する場合は「JSONバックアップ」で書き出し、移行先で「JSON読込」を行ってください。

## 顔写真

「画像追加」から複数画像を登録できます。サムネイル左下の ☆ を押すとメイン画像になり、★ が現在のメイン画像です。

## 名札

会員リストの「名札文言」と「帯色」を設定し、「名札」にチェックを入れた会員を「名札PDF出力」から出力します。

帯文字は背景色に応じて黒 / 白を自動選択します。名札文言が空の場合は帯自体を表示しません。

Chrome / Edge の印刷ダイアログで「PDFに保存」を選択してください。倍率100%を推奨します。

## GitHub Pages

リポジトリ名: `member`

GitHub Pages の Source を **GitHub Actions** に設定すると、`main` への push で `.github/workflows/pages.yml` が公開します。
